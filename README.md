## 📖 نظرة عامة

**نبراس** هي منصة تعليمية ذكية متطورة مدعومة بالذكاء الاصطناعي، تم تطويرها بواسطة **SEVEN_CODE7**. توفر المنصة تجربة تعليمية تفاعلية شاملة مع مجموعة واسعة من الأدوات والميزات المبتكرة.

## 🚀 البدء السريع

### المتطلبات

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت (للذكاء الاصطناعي)
- JavaScript مفعل

### التثبيت

1. **تحميل الملفات**
   ```bash
   git clone https://github.com/yourusername/nebras.git
   cd nebras
   ```

2. **فتح المشروع**
   - افتح ملف `index.html` في المتصفح
   - أو استخدم خادم محلي:
     ```bash
     python -m http.server 8000
     ```
   - ثم افتح `http://localhost:8000`

### الإعداد

1. **مفتاح API** (مهم):
   - افتح ملف `assets/js/config.js`
   - استبدل مفتاح API بمفتاحك الخاص
   - احفظ التغييرات

2. **التخصيص**:
   - افتح الإعدادات من الواجهة
   - اختر الثيم والألوان المفضلة
   - احفظ الإعدادات

## 🎯 كيفية الاستخدام

### المحادثة الأساسية

1. اكتب سؤالك في حقل الإدخال
2. اضغط "إرسال" أو Enter
3. انتظر الرد من الذكاء الاصطناعي
4. استمر في المحادثة

### إرسال الصور

1. اضغط على زر "📎 صورة"
2. اختر صورة أو أكثر
3. أو اسحب الصور وأفلتها
4. اكتب سؤالك عن الصورة
5. أرسل

### تبديل الأوضاع

1. اختر وضعاً من القائمة الجانبية
2. استخدم الأدوات الخاصة بكل وضع
3. استمتع بتجربة تعليمية مخصصة

### المختبر البرمجي

1. اختر "المختبر البرمجي" من القائمة
2. اكتب كودك في المحرر
3. اختر اللغة البرمجية
4. اضغط "تشغيل" لرؤية النتيجة

### التحديات اليومية

1. اختر "التحديات اليومية"
2. اقرأ التحدي المعروض
3. اكتب إجابتك
4. أرسل واحصل على النقاط

